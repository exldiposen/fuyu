# 浮屿 · Fuyu — Floating Isle

> 一座漂流的岛。每座岛都有一条规则。
> 找回记忆碎片，才能记起回家的路。

《浮屿》是一款开源的网页叙事游戏（interactive fiction）。
你扮演一个在浮屿上醒来的失忆旅人——不记得自己是谁，只记得两个字：**回家**。
每一座漂来的岛都拥有一条奇怪的规则；只有理解规则，你才能穿过这座岛，
拾起散落其中的记忆碎片。碎片拼得越完整，回家的路就越清晰。

灵感来自《奥德赛》的归乡母题，以及《漂流少年》《空之境界》对"规则世界"
与"碎片化叙事"的表达。本项目为原创设定，不包含任何上述作品的角色、画面与文本。

## 当前状态

**v0.1 垂直切片 · 第一座岛「静默屿」已可玩**

- 玩法：阅读 → 理解规则 → 做出选择 → 收获记忆碎片
- 进度自动保存在浏览器本地（localStorage）
- 零依赖、零构建：clone 下来即可运行

## 快速开始

无需安装任何依赖，任选一种方式启动本地服务器：

```bash
# Python 3
python -m http.server 8000
```

然后打开 <http://localhost:8000>。

> 注意：项目使用 ES Modules 与 fetch，必须通过本地服务器访问，
> 直接双击 index.html 会因浏览器安全策略无法运行。

## 目录结构

| 路径 | 说明 |
| --- | --- |
| `index.html` | 应用入口 |
| `assets/` | 样式与视觉资源 |
| `data/worlds.json` | 所有岛屿（世界）的内容数据 |
| `src/` | 游戏引擎与界面代码 |
| `docs/CONCEPT.md` | 世界观与设计文档 |
| `docs/WORLD_RULES.md` | 如何为《浮屿》贡献一座新岛 |
