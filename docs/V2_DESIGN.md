## 0. 一句话

> 九塔尽灭的灰海上，少年带着最后一粒火种出航；火在他掌心里站了起来，变成一个少女。
> 她没有影子，不记得自己是谁，叠衣服的动作和收灯的人一模一样。
> 要让世界重新亮起来，先要弄清楚她是什么——以及，她是由什么做成的。

**主题**：boy meets girl——遇见她 = 遇见你自己丢掉的东西；爱她 = 赎回你烧掉的过去。

---

## 1. 世界观

- 漂流岛群由**九座灯塔**指引。灯亮着，雾就进不来。
- **灯烧的不是油，是"等的人舍不得忘的东西"**（序章老人伏笔）。灯收走记忆作燃料，替出海未归的人保管。
- 灯一盏盏灭了。收灯的人在收——他挨个把灯**叠好、收走**，像收拾遗物。被收走的灯化作雾，罩住整片海。
- 主角的村子守着最后一粒火种。故事开场那晚，火种将尽，少年带火出航，去找传说中还没灭的第一塔。

## 2. 她：灯璃（全书最大的谜题）

**表面设定**：由火而生的少女。垂目，安静，说话很轻；光以记忆为薪——拾回碎片她亮一分。登场名场面：
> 火在你掌心里站了起来。……一个由火构成的少女，坐在你的船头，点亮了自己。
> 她睁开眼："……好暗啊。"然后她看见你："……不过，你来了。"
> 雾在离船十步的地方停住了。整片海亮起来——不是日出那种亮，是深夜房间里有人为你留了一盏灯的那种亮。

**神秘阶梯**（全书按此顺序释放，一次只亮一级）：

| 阶 | 线索 | 释放时机 |
| --- | --- | --- |
| 1 | 她很新："我记得火里很挤，很暖。有人在等——等的人不是我，被等的也不是我。" | 序章 ✅ |
| 2 | **她没有影子。**船上所有东西都有影子，只有她没有（玩家可自行发现，不点破） | 序章 ✅ |
| 3 | **世界不回应她的方式**（一组同构线索，散在各岛）：无风之海**不记她的航迹**、回声阶**不收她的声音**、无名渡**不收她的船票**（水不沾她）、秤星岛**称不出她的重量**、纸月剪纸人**认识她**、每座岛的烧痕她都认识 | P2 ✅ |
| 4 | 问她的过去，她的光会变暗（机制化：**追问 = 付一块记忆作薪**，纸月已实装：付出「火」→ 她说出"火里有很多名字，数到你的那个时，停了很久"） | 中盘 ✅ |
| 5 | **她叠纸衣的动作，和收灯的白手一模一样**——"手自己会。"（纸月夜话三分支：问 / 追问（代价）/ 陪她叠） | 纸月夜话 ✅ |
| 6 | 真相：**她由被灯收走的记忆构成**——收灯人在塔顶亲口道出：「你养的是所有人回不去的那部分，攒成的一个她。」 | 终章 ✅ |
| 7 | 最后一层：**你的一块**——出海前夜你求灯"如果回不来，就让我忘了回家这条路"；连这个，她都替你收着 | 终章 ✅ |

**她的规则（机制）**：碎片数 = 亮度 = 她的"存在感"。中盘新增张力：**探问她的过去会让她变暗**（选择问 = 花光），玩家在"知道她是什么"与"让她存在"之间做真实的取舍。

## 3. 他：收灯人（反派，安静的）

- 形象：很高，很白的手，提一只收灯用的木箱。他收灯的动作像叠衣服，轻，熟练，带着一种收拾遗物的温柔。
- 逻辑："我不是熄灯。烧过的东西，要收好。"他不认为自己是恶——第一塔烧掉的是他等的那个人；从那以后他挨个把灯收掉，"免得再有人烧成光"。
- 出场仅三次：序章末（村外收灯的白手，惊鸿一瞥）、中盘（还潮之湾，当着你的面收走一盏她刚焐亮的灯桩，第一次正面交锋——无战斗，只有对话）、终章（第一塔下，他说出她的真相，作为武器："你知道她是什么吗？灯的燃料。你点得越亮，她烧得越快。"）。
- 他与她的镜像：同一个动作（叠）、同一种构成（被灯收走的东西）、相反的选择（他收，她给）。

## 4. 岛屿：九岛暗调重写（机制全保留，命名回归安静）

沿用 v1.3 的九岛机制骨架（回声 / 折页 / 代价 / 归还 / 组合），文案全部按暗调神秘重写；**不更名、不 BOSS 战**。每座岛 = 一段被收走的记忆的形状 + 一次"她认出什么"的神秘递进。终章第一塔 = 三段**仪式**（说两遍才开的门、折起来的影子、以薪易薪的灯芯盒）——机制合流但气质是告别，不是战斗。

## 5. 结局矩阵（4 个，暗调）

| 结局 | 类型 | 条件（草案） | 核心画面 |
| --- | --- | --- | --- |
| **拂晓** | GE | 碎片归还仪式完成（全碎片 + 逐岛"焐开烧痕"） | 记忆各归其主，她**第一次有了影子**——以人的方式留下；塔亮起，像很多迟到的一起醒来。你手里握着一件叠得整整齐齐的外套 |
| **守夜** | OE | 不点塔，带她回村 | 村子学会在黑暗里生活；夜里冷时她把光调小一点，省给你看路。多年后雾里有别的小灯亮起——不是塔，是一户一户学你们的人家 |
| **燃料** | BE | 点塔（她作为燃料燃尽） | 她在光里向你挥手，从清晰到透明，像一封信被读完。塔亮得很好，九岛从雾里显形。你只记得她最后说："别省着用。" |
| **收灯** | 暗黑 | 终章接过白手套 | 收灯人散在雾里，白手套很合手。你走遍九岛把灯一盏盏收进袖子；最后一盏的塔顶，坐着一个由光构成的少女。你向她伸出手——她认出了手套，往后退了一步 |

> 四结局数量与引擎现状一致（零改动）。结局条件细节在 P3 定稿。
