## v1.3.0 — 2026-10-24

### 新的岛

- 新增「重诺屿」：一座把许出去的话打成绳结的岛。规则是“话要许两遍：
  第一遍给海听，第二遍才算数”——第一次把**回声**与**代价**叠在同一个选项上；
  不许愿的人要从黑色的水里蹚过去，照样能走到尽头。
- 新增「叠浪」：一片被折起来的海。先**折页**折起脚下这层海，之字路才会出现；
  折起的路每一步要走两遍（**回声**）才踩得实，抄近路跳下去会被浪送回起点。
- 海图扩大为九座岛 + 一座灯塔；新增 `vow` / `fold` 两种海面与音色氛围；
  碎片增至 10 块（新增「别」「折」），手记增至 27 则，星图新增三条连线。

### 回航的理由

- 结局屏新增**结局收藏**：见过的结局亮出名字，没到的只留序号与
  “还有 N 个结局在雾里”的提示。
- 结局屏与航海日志新增**「带走星图」**：把记忆星图导出为 1080×1080 PNG
  分享图，全部 Canvas 程序化绘制。

### 工程

- 存档改为**只存 ID**：序列化不再保存碎片 / 手记正文，恢复时从
  `worlds.json` 重新水化；改版文案后旧存档读到的是新内容，
  引用已消失内容的存档条目会被安全丢弃。旧 v2 完整对象形态仍可恢复。
- 界面流程纯逻辑抽到 `src/flow.js`（cut-in 决策、海图提示、标题进度、
  结局收藏模型），并在 Node 中直接测试。
- cut-in 新增频率开关：「航行须知」里可在“全部”与“仅靠岸与结局”之间
  切换，持久化到 `fuyu-cutin-v1`；静海仍然永远不触发。
- 无障碍：日志标签页支持左右方向键并补全 `aria-controls` / `aria-labelledby`；
  从游戏打开海图、打开日志后焦点移动到对应标题 / 标签。
- 修复 900–1100px 区间潮红 / 深蓝海图表头与提示条比图框宽约 32px 的错位。
- 测试从 19 个增加到 31 个（新增两岛航线、回声 × 代价、折页 × 回声、
  存档水化与旧形态兼容、界面纯逻辑）。

## v1.0.0 — 2026-10-19

### 航线

- 序章「海图」、七座岛与灯塔，共 67 个场景。
- 静默屿、无风之海、回声阶、无名渡、秤星岛、纸月、归潮、灯塔。
- 8 块记忆碎片、21 则观察手记、4 个结局（归乡 / 守灯 / 漂流 / 无名）。
- 海图自由选择靠岸顺序；至少四座岛后灯塔亮起。

### 机制

- 引擎重写为纯状态机：旗标、条件、`requires` / `onlyIf`、碎片代价、
  指定碎片、回声确认、折页、失而复得、结局。
- 回声阶：同一步必须走两次，第一次只是“余音”。
- 纸月：先折页，折起来的世界才会出现路。
- 秤星岛：真的从碎片列表里拿走一块记忆；也可以欠着海的账。
- 归潮：把失去的碎片还回来，并标记“海还回来的”。
- 灯塔：欠账未清时，“回家”锁定；还清后才可选择。

### 界面

- 全新视觉：深海、薄雾、纸纹、琥珀灯光；字体、留白与动效重做。
- 海图：七座岛 + 灯塔、航线、罗盘、未解锁状态、已靠岸但未拾回记忆的区分。
- 航海日志：记忆星图、碎片卡片、规则摘录、手记、结局收藏。
- 记忆星图：八颗星连成灯塔的轮廓；已点亮 / 未点亮、动画连线。
- 结局页：四种结局、碎片统计、星图、再次起航。
- 代价选择器、确认弹层、航行须知、Toast。
- 键盘：数字键选择、J / M / S / Esc / ?；移动端与减少动态适配。

### 氛围

- Canvas 程序化海面：星空、雾团、潮汐线、灯塔剪影与光束、纸月、
  回声环、秤星、归潮航迹、结局色调。
- 点击海面产生涟漪；指针轻微视差。
- Web Audio 合成环境声：粉噪声海浪、持续音、钟声；按岛切换音高与滤波。
- 不加载任何图片、音频或字体文件。

### 存档

- 存档升级为 `fuyu-save-v2`，保存旗标、手记、已知规则、失去的碎片、结局。
- 自动识别并接续 v0.1 的 `fuyu-save-v1`。
- 跨周目记录 `fuyu-meta-v1`：已抵达的结局、点亮的记忆之星。
- 标题页显示“已抵达 X / 4 个结局”和记忆星图。

### 工程

- 零依赖、零构建；`npm start` 启动本地服务器。
- `npm run validate`：场景可达性、引用、出口、旗标、星图、灯塔校验。
- `npm test`：19 个引擎 / 完整航线测试（Node 内置 test runner）。
- GitHub Actions：push / PR 时自动校验。
- `?debug=1` 提供本地跳转钩子，方便内容调试。
- 文档重写：README、CONCEPT、ROADMAP、WORLD_RULES、CHANGELOG。
