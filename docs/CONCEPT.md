# 概念文档：浮屿

> 漂流向归乡。

## 一句话

你是一个失忆的旅人，在一群永远漂流于海上的岛屿之间醒来；每座岛都拥有一条
奇怪的规则，而你的记忆碎片散落在各岛之间。理解规则、付出代价、拾回碎片，
最后在灯塔下决定：要不要回家。

## 核心循环

1. 漂到一座新岛
2. 观察，发现并理解这座岛的规则
3. 在关键时刻做出选择——对规则的理解程度决定你能否通过，也决定你留下什么
4. 收获一块记忆碎片（也可能失去一块）
5. 回到海图，选择下一座岛
6. 当灯塔亮起，走向它，选择一种归途

## 航线结构

v1.0 是一条完整的航线：序章 → 七座可自由选择顺序的岛 → 灯塔。
灯塔至少需要四座岛的微光才会从雾里出现；四座岛之后，玩家可以选择继续航行，
也可以提前走向结局。

| 世界 | 规则 | 机制 |
| --- | --- | --- |
| 序 · 海图 | —— | 醒来、拾起刻痕、展开海图 |
| 静默屿 | 说出口的话会化作雾，飘向你真正想去的地方 | 说话与沉默；雾的方向 |
| 无风之海 | 这片海上没有风，只有旧日的航迹 | 在别人的航迹里认出自己的那一条 |
| 回声阶 | 每一级台阶都会把你的脚步还给你；只有重复的，才算走过 | 同一步必须走两次 |
| 无名渡 | 名字没有用；只有你做过的事会被记住 | 用已有的碎片作为“做过的事”换取船票 |
| 秤星岛 | 这座岛给一切称重；你带走的，都要留下等重的东西 | 真的失去一块记忆；也可以欠着 |
| 纸月 | 月亮是纸折的；你折一下天，路就换个方向 | 先折页，才会出现路 |
| 归潮 | 你扔进海里的，都会在退潮时回来 | 归还失去的碎片；海还记着账 |
| 灯塔 | 灯不催人。它只是亮着，等你回来 | 四个结局 |

## 规则即机制

“每座岛有一条规则”不能只停留在旁白里。v1.0 的规则至少满足以下一种：

- **改变操作**：回声阶要重复同一步；纸月要先折页。
- **改变资源**：秤星岛收走一块碎片；归潮把它还回来。
- **改变路径**：无名渡根据你已有的碎片开放不同的“我是谁”。
- **改变叙述**：静默屿的话会变成雾；无风之海的路是别人的航迹。

一条好规则必须自洽，并且与这座岛的故事互为因果。规则是故事的形状，不是装饰。

## 记忆碎片与星图

八块碎片分别关于：一个被划掉的名字、一盏灯、一场雨、一个被喊出的名字、
一件做过的事、一个承诺、一轮纸月、一扇没有锁的门。

碎片不会直接给出答案，它只提供一个细节。收集到的碎片会在“记忆星图”上点亮
对应的星；连起来的线不是剧情流程图，而是一个人在雾里逐渐显出的轮廓。

## 代价与归还

《浮屿》不想让“回家”变成一条无摩擦的进度条。

- 在秤星岛，你可以放下一块记忆；那会真的从你的碎片列表里消失。
- 你也可以拒绝付款，欠着海的账；海会在灯塔下等你。
- 在归潮，被拿走的东西会回来，但会带着被海水磨过的痕迹。
- 在灯塔下，“回家”需要足够的碎片，也需要你不再欠着什么。

代价不是失败，而是让最后的选择有重量。

## 四种结局

| 结局 | 条件 | 情绪 |
| --- | --- | --- |
| 归乡 | 至少六块碎片，且已还清海上的账 | 终于记起自己是谁，也终于忘了自己是怎么回来的 |
| 守灯 | 至少四块碎片 | 你留下，成为别人的灯 |
| 漂流 | 任何时候都可以选择 | 你没有回家，但你知道家在哪里 |
| 无名 | 明确说“我不知道”，或记忆太少 | 醒来时，只记得两个字：回家 |

没有“完美结局”。只有你愿意用哪些记忆，换哪一种归途。

## 世界观

- **浮屿**：一片没有固定航线的群岛。岛屿彼此远离，又会在雾中靠近。
- **规则**：每座岛都拥有一条“世界规则”。它从不解释自己，只能被观察。
- **记忆碎片**：每一块碎片都关于“你是谁 / 你的家”。它让“我”更具体，
  而不是让剧情更确定。
- **归乡（nostos）**：整段旅程的目标。玩家最终要回到的不是一个地点，
  而是“被记住的自己”。
- **灯塔**：所有岛的中间。灯不催人，它只是亮着。

## 设计原则

1. **氛围优先**：文字、节奏、留白比机制更先被感受到。
2. **先观察，后理解**：不在开头解释规则，让“没理解”本身成为提示。
3. **规则必须能被玩到**：每条规则至少改变一种操作、资源或路径。
4. **碎片关乎身份，而非剧透**：每块碎片都让“我”更具体。
5. **代价让选择有重量**：允许玩家失去、欠下、再归还。
6. **不惩罚探索**：走错路也能留下手记；每条路都能走到出口。

## 灵感与原创边界

灵感来自荷马《奥德赛》的归乡母题，《漂流少年》的“世界规则”设定，以及
《空之境界》的乱序碎片化叙事。本项目不复制任何作品的角色、画面、音乐与
文本，所有设定、岛屿、文本与程序均为原创。可以在 README 与本文档中引用
灵感来源，但不允许直接搬用受版权保护的内容。

## 命名

- 中文名：**浮屿**（漂浮的岛屿，也含“无根”之意）
- 英文名：**Fuyu · Floating Isle**
- 主题词：**nostos**（希腊语“归乡”，《奥德赛》的母题）
