# 概念文档：浮屿

> 漂流向归乡。

## 一句话

你是一个失忆的旅人，在一座永远漂流于海上的群岛中醒来；每座岛都拥有一条
奇怪的规则，而你的记忆碎片散落在各岛之间。理解规则、拾回碎片，才能记起
自己是谁，找到回家的路。

## 核心循环

1. 漂到一座新岛
2. 观察，发现并理解这座岛的规则
3. 在关键时刻做出选择——对规则的理解程度决定结局
4. 收获一块记忆碎片（也可能失去什么）
5. 起航，进入下一座岛

## 世界观

- **浮屿**：一片没有固定航线的群岛。岛屿彼此远离，又会在雾中靠近。
- **规则**：每座岛都拥有一条"世界规则"。它从不解释自己，只能被观察。
  规则必须自洽，并且与这座岛的故事互为因果。
- **记忆碎片**：每一块碎片都关于"你是谁 / 你的家"。碎片不会直接给出答案，
  它只提供一个细节：一盏灯、一种味道、一句没说完的话。
- **归乡（nostos）**：整段旅程的目标。玩家最终要回到的不是一个地点，
  而是"被记住的自己"。

## 三条设计原则

1. **氛围优先**：文字、节奏、留白比机制更先被感受到。
2. **规则可以被玩家自己发现**：不在开头解释规则，让"没理解"本身成为提示。
3. **碎片关乎身份，而非剧透**：每块碎片都让"我"更具体，而不是让剧情更确定。

## 灵感与原创边界

灵感来自荷马《奥德赛》的归乡母题，《漂流少年》的"世界规则"设定，以及
《空之境界》的乱序碎片化叙事。本项目不复制任何作品的角色、画面、音乐与
文本，所有设定均为原创。可以在 README 与本文档中引用灵感来源，但不允许
直接搬用受版权保护的内容。

## 命名

- 中文名：**浮屿**（漂浮的岛屿，也含"无根"之意）
- 英文名：**Fuyu · Floating Isle**
- 主题词：**nostos**（希腊语"归乡"，《奥德赛》的母题）
